🔗 네이버 검색광고 API 자동 수집

API 키가 등록된 업체들을 한 번에 순서대로 수집해요. 아래 기간을 비워두면 이번 달 1일~어제까지만 가져와요. 기간을 직접 입력하면(예: 6개월 전부터) 그 기간 전체를 가져와요 — 네이버 API가 한 번에 최대 90일까지만 조회를 허용해서, 긴 기간은 90일 단위로 자동으로 나눠서 순서대로 요청해요.
API 키가 등록된 모든 업체의 키워드를 순서대로 가져와요. 위와 같은 기간(비워두면 이번 달)을 그대로 써요. 업체당, 기간 구간(90일)당 캠페인이 많으면 몇 분씩 걸릴 수 있어서, 업체 수·기간이 길면 전체적으로 꽤 오래 걸릴 수 있어요(창을 닫지 말고 기다려주세요).
▸ 연동된 광고주 자동 등록 (베타 — 현재 지원 안 됨, 참고용)
테스트 결과, 네이버 검색광고 API는 "권한 설정(운영 관리)"으로 연결된 계정 구조에서는 연동 계정 목록을 자동으로 제공하지 않아요(정식 대행사 등록 계정만 지원). 그래서 이 기능은 현재 사용할 수 없고, 아래 "API 키 설정"에서 업체별로 개별 등록해주셔야 해요.
▾ 공용 API 키 등록 (운영 관리 권한이 있는 계정 — 한 번만 등록)
"운영 관리" 권한으로 여러 업체 계정을 다루고 계시면, 그 권한을 가진 계정(예: kileog64)의 API 키를 여기 한 번만 등록해두세요. 아래 "업체 추가"에서 업체마다 CUSTOMER_ID만 입력하고 이 키를 선택하면, 키를 따로 발급받을 필요 없이 바로 연동돼요. (searchad.naver.com → 광고시스템 → 도구 → API 사용 관리 에서 확인)
▾ 업체 추가 (CUSTOMER_ID + 공용 키 선택, 또는 업체별 개별 키)
업체마다 네이버에서 발급받은 API 키를 등록해두면, CSV 파일 업로드 없이 자동으로 캠페인 성과를 가져올 수 있어요. 위에서 공용 키를 등록해두셨으면 아래 "사용할 키"에서 바로 선택하시면 되고, 그 업체만 따로 키가 있으면 "개별 키 직접 입력"을 선택해주세요. 한 번 등록해두면 위의 "전체 수집 실행"이 자동으로 이 업체도 함께 수집해요.
특정 업체 하나만 지금 바로 다시 가져오고 싶을 때 써주세요. (평소엔 위의 "전체 수집 실행"만 누르면 돼요. 캠페인/일별/키워드를 지원해요 — 시간대별은 다음 단계) 기간이 여러 달에 걸치면 자동으로 월별로 나눠서 저장돼요.
광고그룹·소재 단위 데이터는 캠페인이 많으면 시간이 오래 걸려서(최대 9분) 별도 버튼으로 분리했어요. 위와 같은 업체/키/기간으로 가져와서, 선택한 기간 중 가장 최근 달에 합쳐서 저장돼요.
키워드 단위 데이터도 캠페인이 많으면 시간이 오래 걸려서(최대 9분) 별도 버튼으로 분리했어요. 위와 같은 업체/키/기간으로 가져와서, 선택한 기간 중 가장 최근 달에 합쳐서 저장돼요. (파워링크/브랜드검색 키워드를 각각 상위 25개씩, 저효율·확대추천 키워드도 함께 골라줘요)
▸ 업체 일괄 등록 (여러 업체를 한 번에 — CSV/줄바꿈 붙여넣기)
업체명과 CUSTOMER_ID를 한 줄에 하나씩, 쉼표로 구분해서 붙여넣으면 한 번에 다 등록돼요. 업체가 아직 없으면 자동으로 새로 만들고, 선택한 공용 키를 전부 함께 연결해요. 각 CUSTOMER_ID는 등록 전에 자동으로 검증하고, 실패한 것만 결과에 표시돼요. (형식: 업체명,CUSTOMER_ID,업종 — 업종은 DB 또는 B2C, 생략하면 아래 기본 업종으로 등록돼요)
첫 줄은 "업체명,CUSTOMER_ID,업종" 헤더로 인식해서 건너뛰어요. 업종 칸은 비워도 되고, DB 또는 B2C만 입력해주세요. 파일을 올리면 아래 목록에 자동으로 채워져요.

⏰ 시간대별 데이터만 추가

이미 등록된 업체·기간에 시간대별 데이터만 병합해요. 매출·비용 등 기존 값은 그대로 유지돼요.
캠페인유형/캠페인/광고그룹/시간대별/PC-모바일 매체 형식이에요.

🔑 키워드/검색어 데이터만 추가

이미 등록된 업체·기간에 키워드/검색어 데이터만 병합해요. 캠페인유형 보고 파워링크·쇼핑검색·브랜드검색에 자동 분류돼요. 파일을 여러 개 올리면 각 파일 제목의 기간을 각각 인식해서 해당 기간에 따로 저장돼요. 매출·비용 등 기존 값은 그대로 유지돼요.
캠페인유형/캠페인/PC-모바일 매체/검색어(또는 키워드) 형식이에요.

🖼️ 소재(광고그룹) 데이터만 추가

이미 등록된 업체·기간에 광고그룹·소재 데이터만 병합해요. API 연결 없이 네이버에서 다운받은 리포트 파일을 그대로 올리면 돼요. 매출·비용 등 기존 값은 그대로 유지돼요.
캠페인유형/캠페인/광고그룹/소재/일별 형식이에요. 소재 열이 없으면 광고그룹 단위까지만 저장돼요.
📊 용량 관리 — 문서 용량 확인, 오래된 데이터 압축

📊 전체 업체 용량 모니터링

업체별 메인 문서·가장 큰 상세 문서(월별 이력로그/상세데이터) 용량이에요. 용량 위험(⚠️)이 뜨면 "오래된 상세 데이터 압축"을 써주세요.

🧹 오래된 상세 데이터 압축 (용량 초과 시 필수)

업체 데이터는 Firestore 문서 1개당 1MB 제한이 있어요. 업체 하나가 오래 쌓이면 이 한도를 넘어서 저장이 전부 안 되는 사태가 생겨요(저장 실패 메시지에 용량 초과가 뜨면 여기를 쓰세요). 최근 N개월은 그대로 두고, 그보다 오래된 달의 키워드/검색어/시간대별/원본 변경이력처럼 무거운 상세 데이터만 지워서 용량을 줄여요. 매출·비용·전환수 같은 핵심 숫자와 일별 그래프는 그대로 유지돼요.
🔒 권한 · 계정 — 업체별 열람 권한, 관리자 이메일

🔒 업체별 접근 권한 설정

특정 업체를 지정한 팀원 이메일만 볼 수 있게 제한해요. 비워두면(기본값) 로그인한 팀원 전체가 볼 수 있어요. 중요: 이 화면만으로는 실제로 막히지 않아요 — 아래에서 안내하는 Firestore 보안 규칙을 Firebase 콘솔에 붙여넣어야 실제로 적용돼요.

👑 관리자 계정 관리

여기 등록된 이메일로 로그인하면 전체 업체 데이터를 다 볼 수 있어요(관리자). 등록 안 된 계정은 자기 업체에 허용된 업체만 보여요(유저) — 위의 "업체별 접근 권한 설정"에서 업체마다 허용 이메일을 등록해줘야 해요.
🎨 업체 설정 — 색상, 목표(KPI)

🎨 업체 색상 변경

신규 업체는 색이 자동으로 랜덤 지정되는데, 여기서 원하는 색으로 바꿀 수 있어요. 대시보드 아이콘·강조색·차트 색에 전부 반영돼요.

🎯 목표(KPI) 설정

업체별 목표를 설정하면 요약 대시보드에서 최근 기간 실제 성과와 비교해서 알려줘요.
설정하면 이번 달 예산 소진 페이스를 실시간으로 예측해서 알려줘요.
🏢 업체 관리 · 삭제 — 업체 추가, 되돌리기, 삭제

➕ 업체만 개별 추가

아직 광고 성과 데이터 없이 업체만 먼저 등록하고 싶을 때, 여기서 이름만으로 바로 추가할 수 있어요. 성과 데이터는 나중에 데이터 보고서를 업로드하면 자연스럽게 채워져요.

↩️ 최근 업로드 되돌리기

실수로 잘못된 파일을 올렸다면, 업체를 선택하고 바로 아래 버튼으로 되돌릴 수 있어요. (업체별로 가장 최근 저장 1회분만 보관돼요 — 그 이전 상태로는 되돌릴 수 없어요)

🗑️ 데이터 삭제

되돌릴 수 없어요. 삭제 전에 한 번 더 확인해주세요.
위 업체·기간을 그대로 두고, 키워드/검색어 데이터(TOP·제외추천)만 지워요. 매출·비용 등 나머지 값은 유지돼요.
